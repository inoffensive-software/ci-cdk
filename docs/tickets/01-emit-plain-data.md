# 01: Emit plain data

**Spec:** `docs/specs/0001-core-doc-and-yaml-emitter.md`

**What to build:** A consumer can import `fromValue` and `renderDoc` from the package root and turn
plain nested JavaScript data into YAML text. This is the first thread through every layer: the `yaml`
dependency, the `Doc` tree, the boundary parser, the serializer, the header knob, and the test seam.
When it lands, the package does something real and the format contract has its first golden.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] `yaml` is a runtime dependency at exact version `2.9.1`, with no range, and is imported by the
      serializer in the same change that adds it, so the dependency check passes.
- [ ] The `Doc` union exists with `map`, `seq` and `scalar` node kinds, an optional `tag` field on each
      kind, and the `map`/`seq`/`scalar`/`block`/`tagged` constructors. `block` produces a literal
      scalar. The `DOC` unique symbol and `LeafNode` interface exist in core.
- [ ] `fromValue` accepts strings, finite numbers, booleans, `null`, arrays and plain objects, and
      lowers a `DOC`-carrying value by calling it before any other classification.
- [ ] Object key order and array order survive into the output at every depth.
- [ ] The core barrel exports the public surface, and the package entry point re-exports it. The
      `identity` placeholder export is deleted.
- [ ] `renderDoc(doc, { header? })` emits two-space indentation, block collections, sequences indented
      under their key, LF line endings and exactly one trailing newline.
- [ ] The default header is `# Generated by @inoffensive/ci-cdk. Do not edit.` with no blank line after
      it, and `{ header: "" }` emits no header at all.
- [ ] An empty map emits `{}`, an empty sequence emits `[]`, and a document with no entries still ends
      with exactly one newline.
- [ ] The harness test and its golden are replaced by real tests at the core-barrel seam, so `pnpm test`
      never runs without a real assertion.
- [ ] At least three goldens are pinned with `toMatchFileSnapshot`: nested map, nested sequence, and
      empty document.
- [ ] `pnpm check` passes.
